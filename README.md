# 💻 Aulas de HTML5 & CSS3 — Fatec Carapicuíba

Repositório destinado ao armazenamento de exercícios, projetos e atividades práticas desenvolvidos durante as aulas de desenvolvimento web (HTML5 e CSS3) na **Fatec Carapicuíba**.

---

## 📌 Sobre o Repositório

O objetivo deste repositório é documentar o aprendizado das linguagens de marcação e estilo, acompanhando a evolução dos projetos desenvolvidos ao longo do semestre letivo.

---

## 🛠️ Tecnologias e Ferramentas

* **HTML5** — Estruturação de conteúdo web semântico
* **CSS3** — Estilização, layouts responsivos, Flexbox e Grid
* **VS Code** — Editor de código utilizado no desenvolvimento
* **Git & GitHub** — Controle de versão e hospedagem do código
