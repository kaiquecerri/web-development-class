Discussão em Grupo (15 min)
Organizar a turma em grupos de 3–4 pessoas. Cada grupo responde oralmente e um porta-voz compartilha:


1. Por que praticamente todo site hoje usa HTTPS?  
   1° - Os navegadores atuais alertam usuários, informando que o site não é seguro, caso não tenha HTTPS. Assim tirando a credibilidade de sites que não possuam a certificação.
   2° - Aumentar a segurança e criptografia do usuário e do servidor.

2. O que aconteceria se navegadores não interpretassem HTML?  
   Iriamos ver algo como um arquivo de texto, parecido como quando abrimos uma requisição json no navegador, mostrando todas as tags, textos e scripts incluídos na página.


3. Qual a maior mudança da Web 1.0 para a Web 2.0?  
   Sites se tornaram interativos e dinâmicos.


4. Como a IA pode mudar o desenvolvimento web no futuro?  
	Facilidade de criar aplicações web -> devido a geração de código por IA, muitas páginas poderiam ser criadas mais rapidamente e facilmente, sendo possível "qualquer um" criar um site em minutos.
	Sites menos confiáveis -> A IA ainda não tem a capacidade de cuidar de toda a parte de segurança sozinha, então quem não é especializado não conseguirá ver os problemas de segurança logo de cara, deixando os usuários e o servidor vulnerável
	Menor empregabilidade para desenvolvedores web -> por conta dessa facilidade toda, muitos devs web deixaram de ser contratados em troca da IA.
